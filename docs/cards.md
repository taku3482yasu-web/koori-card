## 1. 書き方（案）

| 書き方 | 意味 |
|---|---|
| Lv | 左上の丸い数字。そのカードを出す・使うのに必要なプレイヤーレベル（決定：とりあえず） |
| パワー | 1000 きざみ。Lv1 は 1000〜4000、Lv2 は 4000〜7000、Lv3 は 7000〜10000 くらい |
| 【出たとき】 | 場に出たときに 1 回だけ使える |
| 【やられたとき】 | 場から墓地へ行ったときに使える |
| 【DT】 | ドタバタトリガー（シールドから来たらタダで使える） |
| 速攻 | 出たターンに攻撃できる |
| 2 枚割り | シールドへの攻撃で 2 枚割る |
| ブロッカー | アンタップしていれば、相手が攻撃したとき（シールド・ほかのモンスター・ダイレクトアタック どれでも）かわりにバトルを受けられる。ブロックしたらタップする |
| タップ | 攻撃した・ブロックしたモンスターは横向き（タップ）になり、次の自分のターンのはじめに戻る（アンタップ） |
| 止める | 選んだモンスターは、次の相手のターンに攻撃できない |
